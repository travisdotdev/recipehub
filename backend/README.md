# RecipeHub Backend

Backend service for RecipeHub recipe application.

## Requirements
- Java 21
- Maven
- MySQL 8.0.40 

### API Key
- Spoonacular API key (get one at [Spoonacular's website](https://spoonacular.com/food-api))


## Running the Backend

1. Clone the repository
2. Add your Spoonacular API key to `application.properties`
3. Run with: `mvn spring-boot:run`

Server starts at `http://localhost:8080`
